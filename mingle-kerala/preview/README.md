# Mingle Kerala visual previews

- `design-preview.html` is a self-contained static visual preview of the new Mingle Kerala branding and bilingual landing design. Its EN/മലയാളം toggle works inside the preview.
- `desktop.png` and `mobile.png` are screenshots of that HTML, **not screenshots of a running Next.js backend**.
- The real application source is in `app/`, `components/`, `lib/`, `prisma/`, and `server/`.
- The design preview contains no real login, payments, realtime chat, or database interactions.
